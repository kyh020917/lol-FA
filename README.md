# 롤 게임 알림 디스코드 봇

롤 계정을 등록하면 **게임 시작 / 종료(승패·LP) / 하루 요약**을 계정 전용 채널에 임베드로 알려주는 봇입니다. (Python, 한국 서버 전용)

## 명령어
| 명령어 | 권한 | 설명 |
|---|---|---|
| `/계정추가 라이엇아이디` | **관리자** | `닉네임#태그` 입력 → 계정 전용 채널 생성 후 추적 시작 |
| `/계정삭제 계정 [채널삭제]` | **관리자** | 추적 중단 (기본: 채널도 삭제) |
| `/계정목록` | 모두 | 추적 중인 계정과 채널 |
| `/알림설정 계정 ...` | 관리자 또는 등록한 사람 | 시작/종료/일일요약 on·off, 게임종류 필터, 시작 알림 멘션 역할 (옵션 없이 쓰면 현재 설정 표시) |
| `/전적 계정 [판수]` | 모두 | 최근 1~10판 전적 + 현재 티어 (등록 안 된 `닉네임#태그` 도 조회 가능) |

## 알림 내용
- **시작**: 게임 모드(솔로랭크/자유랭크/일반/칼바람/아레나 …), 챔피언(아이콘), 현재 티어, 시작 시각
- **종료**: 승리/패배/다시하기, KDA, CS(분당), 챔피언 딜량, 게임 시간, **LP 변동(승급·강등 포함)**, 현재 티어, 2연승 이상이면 연승/연패 표시
- **일일 요약**: 매일 23:59:59(기본 Asia/Seoul) — 몇 승 몇 패, 총 LP 변동, 플레이한 챔피언 (그날 게임이 없으면 생략)
- 모든 알림에 **딥롤 바로가기** 버튼

## 설치 / 실행
1. 디스코드 개발자 포털에서 봇 생성 → Token 복사
   - 초대 링크 scope: `bot`, `applications.commands`
   - 봇 권한: **채널 관리**, 채널 보기, 메시지 보내기, 임베드 링크
2. https://developer.riotgames.com 에서 **Development API Key** 발급 (24시간마다 만료)
3. `.env.example` 을 `.env` 로 복사하고 `DISCORD_TOKEN`, `RIOT_API_KEY` 입력 (`DEV_GUILD_ID` 에 서버 ID를 넣으면 명령어가 즉시 등록됨)
4. 실행
```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python bot.py
```

## 개발용 키 주의사항
- 개발용 키는 **24시간마다 만료**됩니다. 로그에 `Riot API 키가 만료되었거나 …` 가 뜨면 새 키로 `.env` 를 바꾸고 봇을 재시작하세요.
- 제한: 1초 20회 / 2분 100회 (봇은 여유 있게 18회/95회로 제한). 감시 간격 45초 기준 **약 35계정**까지 여유롭고, 더 많으면 알림이 조금씩 늦어집니다.
- 상시 운영하려면 개발 완료 후 Riot 개발자 포털에서 앱을 등록해 Personal/Production 키를 받으세요.

## 동작 메모
- 시작 알림은 감시 간격(기본 45초) 이내 + Riot이 게임을 인식하는 시점(로딩 화면 무렵)에 맞춰 옵니다.
- LP 변동은 게임 시작 시점의 LP를 저장해두고 종료 후 값과 비교해 계산합니다. 종료 직후 LP가 아직 반영 안 됐으면 최대 3번(약 2분) 더 기다립니다.
- 랭크 게임(솔로/자유)만 LP를 표시합니다. 3분 30초 이내 종료 등 **다시하기**는 승패·LP에 포함하지 않습니다.
- 연승/연패는 같은 게임 모드끼리 계산합니다.
- 봇을 재시작해도 진행 중인 게임을 이어서 감시하며, 같은 게임에 알림이 중복되지 않습니다.
- 알림 채널을 수동으로 지우면 다음 알림 때 자동으로 다시 만듭니다.
